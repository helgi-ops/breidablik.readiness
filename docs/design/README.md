# Design reference — Claude Design mockup

Screenshots of the target design (`Coach Dashboard Hugmyndir.dc.html`, produced in Claude Design).
Use these as the visual source of truth when restyling screens.

## How to use with Claude Code
Claude Code can read images, but you must **paste the screenshot into the chat** (drag-drop or
paste) — it does not auto-open image files. So, per screen:
1. Open the matching screenshot here.
2. Paste it into Claude Code together with a screenshot of the current running app.
3. Ask: "make the app screen match this mockup — colours/spacing/typography per the Design system
   tokens in CLAUDE.md."
4. Small step → screenshot the app → compare → iterate.
