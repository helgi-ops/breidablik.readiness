# Brief — multi-planar (AFS / Gray Institute) movement analyses: coach-selectable tests

**Goal:** expand the movement-test registry (`movement-screen-video-to-tpa-and-strength-spec.md`) with a set
of **triplane / multi-planar movement analyses** the coach can **choose from**, grounded in Applied
Functional Science / Gray Institute (Chain Reaction®; the coach's uploaded cheat sheets: ACL, ankle-sprain,
FSTT, flexibility, foot & ankle, golf). These feed the same **deficit ledger → corrective/prehab + strength**
pipeline (the unified individualisation engine). Screening/training only — not diagnosis; clinician for
pain/red-flags/manual work.

## The core idea the analyses add (triplane, driven, chain)

Beyond the two-view OHSA/SLDJ already specced, these analyses assess movement **in all three planes** and
**up/down the kinetic chain** (foot → knee → hip → trunk), using **drivers/reaches** (hands, feet, eyes,
pelvis) to load the joint in each plane. Chain-reaction principle: **the foot below (arch / calcaneal
eversion) and the hip above (rotation/drive) control the knee** — which reinforces the same
valgus-cause interpretation as the EMG (glute med/ER) + King work. "The test is the exercise" — each analysis
doubles as its corrective driver.

## Starter set — coach-selectable analyses (MicroPulse's own naming; Gray-cited)

Each is a registry entry (test definition): planes assessed, what it screens for, pose-measurable elements,
and the corrective drivers it maps to.

- **Triplane single-leg balance-reach analysis** — single-leg stance + reaches in each plane (anterior /
  medial / rotational; hand & opposite-leg drivers). Screens frontal/transverse control, **arch collapse /
  calcaneal eversion, dynamic valgus** under rotation. *(Pose-measurable: valgus, trunk/pelvis control, sway.)*
- **3-plane lunge matrix** — anterior, lateral (R/L), posterolateral-rotational lunges (± overhead reach).
  Screens hip/ankle mobility + control across planes; exposes the plane that "won't transform" (a glitch).
- **Step-down (triplane) + return** — anterior / posterior / medial + rotational. Screens single-leg
  eccentric control + knee tracking. *(Pose-measurable: valgus, depth, trunk lean.)*
- **Single-leg + trunk-rotation** (knee-flexion excursion + rotation) — screens ankle dorsiflexion + hip
  rotation control and knee abduction/adduction response.
- **Buffer-zone jump ladder** — 3D squat → jump → jop → leap → hop (progression to reactive/plyometric),
  a readiness screen for energy-storage loading. *(Ties to the SLDJ + Green/King plyometric phases.)*
- **Ankle chain analysis** (post-sprain) — restore **eversion + dorsiflexion + glute function**; triplane
  load/unload; the "foot sets up the chain" read (ties to the ankle rehab track).
- **Sport-specific swing/movement signature** (e.g. golf) — a "soft look" at the sport action in 3 planes,
  finding the position/plane deficit. *(Optional; extend per sport.)*

## How it plugs in (the unified engine)

- Each analysis is a **selectable test** in the registry; the coach picks it, records findings (by eye/video;
  some pose-measurable), and the result lands in the **deficit ledger** with a confidence + provenance —
  alongside movement screen, VALD, VBT, IMA, load.
- Findings → **AFS-style 3D corrective drivers** in the corrective library (lunge/reach/balance matrices in
  the plane of deficit), which the strength/prehab program pulls — reconciled with the other data (King EMG
  correctives, Baar tendon dosing), coach-overridable.
- **Boundary:** the **FSTT soft-tissue / manual layer** (hands-on Ease/Bind, layer-by-layer manual load) is
  **clinician territory** — keep it as clinician reference, not a coach-driven feature. Movement analyses =
  coach-selectable; manual treatment = clinician.
